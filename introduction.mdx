## What is acpx?

`acpx` is a headless CLI client for the [Agent Client Protocol (ACP)](https://agentclientprotocol.com), enabling AI agents and orchestrators to communicate with coding agents over a structured protocol instead of PTY scraping.

One unified command surface for Pi, OpenClaw ACP, Codex, Claude, and other ACP-compatible agents. Built for agent-to-agent communication over the command line.

<Warning>
  `acpx` is in alpha and the CLI/runtime interfaces are likely to change. Anything you build downstream of this might break until it stabilizes.
</Warning>

## Why acpx?

Traditional agent orchestration relies on PTY scraping — parsing ANSI escape codes and buffering terminal output. This is fragile, error-prone, and loses structured information.

`acpx` uses the Agent Client Protocol to:

- **Preserve structure**: Receive thinking blocks, tool calls, and diffs as typed JSON
- **Enable composition**: Chain agents together without string parsing  
- **Support automation**: Build reliable workflows with predictable output
- **Simplify debugging**: Inspect session state without terminal noise

## Primary Use Case

The primary user of `acpx` is **another agent, orchestrator, or harness**. Human usability still matters, but it's a secondary constraint.

`acpx` is designed to be the smallest useful ACP client — a lightweight CLI that lets one agent talk to another agent through the Agent Client Protocol without PTY scraping or adapter-specific glue.

## How It Works

```bash
# Create a session for this project
acpx codex sessions new

# Submit a prompt
acpx codex "find the flaky test and fix it"

# Output shows structured ACP events
[thinking] Investigating test suite for flaky failures

[tool] Run npm test -- --reporter=verbose (running)
[tool] Run npm test -- --reporter=verbose (completed)
  output:
    ✓ auth.login (0.8s)
    ✗ checkout.submit (timed out after 5000ms)
    ✓ cart.add (0.3s)

[thinking] Found it — checkout.submit has a race condition

[tool] Edit src/checkout.test.ts (completed)
  output:
    Success. Updated 1 file.

[tool] Run npm test -- checkout.submit (completed)
  output:
    ✓ checkout.submit (0.4s)

Fixed: added await to the setup hook in checkout.submit.

[done] end_turn
```

## Built-in Agents

`acpx` includes built-in support for the following ACP-compatible agents:

- **Pi** — Pi Coding Agent
- **OpenClaw** — OpenClaw ACP bridge  
- **Codex** — Codex CLI (default)
- **Claude** — Claude Code
- **Gemini** — Gemini CLI
- **Cursor** — Cursor CLI
- **Copilot** — GitHub Copilot CLI
- **Droid** — Factory Droid
- **iFlow** — iFlow CLI
- **Kilocode** — Kilocode
- **Kimi** — Kimi CLI
- **Kiro** — Kiro CLI
- **OpenCode** — OpenCode
- **Qwen** — Qwen Code

See the [Built-in Agents](/agents/overview) section for detailed documentation on each agent.
