## Gemini

### Overview

- **Built-in name**: `gemini`
- **Command**: `gemini --acp`
- **Upstream**: [Gemini CLI](https://github.com/google/gemini-cli)
- **Type**: Native ACP support

### Installation

Install the Gemini CLI:

```bash
# Follow instructions at github.com/google/gemini-cli
gemini --version
```

### Basic Usage

```bash
# Create session
acpx gemini sessions new

# Send prompt
acpx gemini "analyze the codebase"

# One-shot execution
acpx gemini exec "summarize changes"
```

### Example

```bash
# Create a review session
acpx gemini sessions new --name review
acpx --approve-reads gemini -s review "review code quality"
```

## Cursor

### Overview

- **Built-in name**: `cursor`
- **Command**: `cursor-agent acp`
- **Upstream**: [Cursor CLI](https://cursor.com/docs/cli/acp)
- **Type**: Native ACP support

### Installation

Install Cursor and ensure the CLI is available:

```bash
cursor-agent --version
```

### Alternative Command Names

Some Cursor installations expose ACP as `agent acp` instead. Override in config:

```json
{
  "agents": {
    "cursor": {
      "command": "agent acp"
    }
  }
}
```

### Basic Usage

```bash
# Create session
acpx cursor sessions new

# Send prompt
acpx cursor "implement feature"

# One-shot execution
acpx cursor exec "explain architecture"
```

### Example

```bash
# Multi-file refactoring
acpx cursor sessions new --name refactor
acpx --approve-all cursor -s refactor "refactor to TypeScript"
```

## Common Patterns

All these agents support the same core acpx features:

### Session Management

```bash
# Works with any agent
acpx <agent> sessions new
acpx <agent> sessions new --name <name>
acpx <agent> sessions list
acpx <agent> sessions show
acpx <agent> sessions history
acpx <agent> sessions close [name]
```

### Session Controls

```bash
acpx <agent> status
acpx <agent> cancel
acpx <agent> set-mode <mode>
acpx <agent> set <key> <value>
```

### Prompt Input

```bash
acpx <agent> "direct prompt"
acpx <agent> --file prompt.md
echo "prompt" | acpx <agent>
acpx <agent> --file - "extra context"
```

### Output Formats

```bash
acpx --format text <agent> "prompt"
acpx --format json <agent> exec "prompt"
acpx --format json --json-strict <agent> exec "prompt"
acpx --format quiet <agent> "prompt"
```

### Permissions

```bash
acpx --approve-all <agent> "prompt"
acpx --approve-reads <agent> "prompt"
acpx --deny-all <agent> "prompt"
acpx --non-interactive-permissions <deny|fail> <agent> "prompt"
```

### Queue Management

```bash
acpx --no-wait <agent> "prompt"
acpx --ttl <seconds> <agent> "prompt"
```

## Configuration

All agents can be configured in `~/.acpx/cli/config.json` or `.acpxrc.json`:

```json
{
  "agents": {
    "gemini": { "command": "gemini --acp" },
    "cursor": { "command": "agent acp" },
    "copilot": { "command": "copilot --acp --stdio" },
    "droid": { "command": "droid exec --output-format acp" },
    "iflow": { "command": "iflow --experimental-acp" },
    "kilocode": { "command": "npx -y @kilocode/cli acp" },
    "kimi": { "command": "kimi acp" },
    "kiro": { "command": "kiro-cli acp" },
    "opencode": { "command": "npx -y opencode-ai acp" },
    "qwen": { "command": "qwen --acp" }
  }
}
```

## Troubleshooting

### Agent Not Found

Ensure the agent CLI is installed and in your PATH:

```bash
<agent-command> --version
```

### Command Not Recognized

Some agents may have different command names on your system. Override in config:

```json
{
  "agents": {
    "<agent>": { "command": "<your-command>" }
  }
}
```

### Session Creation Fails

Check that the agent supports ACP:

```bash
# Test direct invocation
<agent-command> --help | grep -i acp
```

### Permission Issues

Use appropriate permission flags:

```bash
acpx --approve-all <agent> "task"
```
