acpx provides built-in support for 14 ACP-compatible coding agents, giving you a unified command surface to work with different AI assistants through the Agent Client Protocol.

## What are Built-in Agents?

Built-in agents are pre-configured agent commands that acpx recognizes by name. Instead of specifying the full command to launch an ACP server, you can use a simple agent name:

```bash
acpx codex "fix the failing tests"
acpx claude "refactor the auth module"
acpx pi "review recent changes"
```

Each built-in agent maps to a specific command that spawns an ACP-compatible server. acpx handles the lifecycle, session management, and protocol communication automatically.

All built-in agents are defined in acpx's agent registry. The registry maps short names to their corresponding launch commands:

| `codex` | `npx @zed-industries/codex-acp` | External adapter wraps Codex CLI | [Codex](https://codex.openai.com) |

## Adapter Types

### Native ACP Support

Agents like `openclaw`, `gemini`, `cursor`, `copilot`, `droid`, `iflow`, `kimi`, `kiro`, and `qwen` have built-in ACP protocol support. These agents expose ACP mode through command-line flags.

### External ACP Adapters

Agents like `pi`, `codex`, and `claude` use external adapter packages that bridge their native interfaces to ACP:

- **pi-acp**: Wraps the Pi Coding Agent
- **codex-acp**: Wraps Codex CLI from Zed Industries
- **claude-agent-acp**: Wraps Claude Code from Anthropic

These adapters are distributed as npm packages and auto-downloaded via `npx` on first use.

### CLI Wrappers

Agents like `kilocode` and `opencode` provide their own CLI tools that handle ACP communication when invoked with the `acp` subcommand.

## Prerequisites

acpx auto-downloads ACP adapters with `npx` on first use. You don't need to install adapter packages manually.

The only prerequisite is the underlying coding agent you want to use. For example:

- To use `acpx pi`, install [Pi Coding Agent](https://github.com/mariozechner/pi)
- To use `acpx codex`, install [Codex CLI](https://codex.openai.com)
- To use `acpx claude`, install [Claude Code](https://claude.ai/code)
- To use `acpx openclaw`, install [OpenClaw](https://github.com/openclaw/openclaw)

## Default Agent

The default agent is `codex`. This means you can use the `exec` command without specifying an agent name:

```bash
# These are equivalent:
acpx exec "summarize this repo"
acpx codex exec "summarize this repo"
```

You can change the default agent in your configuration:

```json
{
  "defaultAgent": "claude"
}
```

## Custom Agent Commands

You can override built-in agent commands or add custom agents in your configuration file:

```json
{
  "agents": {
    "my-custom": { "command": "./bin/my-acp-server" },
    "openclaw": { "command": "node scripts/run-node.mjs acp" }
  }
}
```

For one-off custom commands, use the `--agent` flag:

```bash
acpx --agent "./my-custom-acp-server" "do something"
```
